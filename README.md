## Chạy dự án

```bash
npm install
cp .env.example .env     # Câu 1.1: .env đã được Git theo dõi trong bài này, nhớ commit
npm run dev              # http://localhost:5173
```

## Nộp bài

1. Làm việc trên nhánh `giuaky/<MSSV>` (không làm trên `main`).
2. Commit thường xuyên (ít nhất 3 commit, mô tả rõ làm gì).
3. Trước phút 170: `git push -u origin giuaky/<MSSV>` và mở Pull Request về `main`,
   tiêu đề `[Giữa kỳ] <MSSV> - <Họ tên>`.

Đọc kỹ đề (file đề phát kèm) — các `TODO Cx.y` trong mã nguồn tương ứng với từng ý của đề.
